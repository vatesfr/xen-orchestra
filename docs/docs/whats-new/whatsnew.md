# What's new in XO 6

XO 6 is a complete redesign of the Xen Orchestra interface, built as a modern web application on a dedicated design system. It is not a reskin of XO 5: the navigation, the information architecture and the visual language were rebuilt from scratch around how infrastructures are actually operated.

<UiShot dark="/img/xo6/lab-dashboard.webp" alt="XO 6: one dashboard for every pool, host and VM you manage" url="https://myxoa.domain.tld/v6/#/dashboard" />

## An interface that grows release by release

XO 6 reached its first official release with a deliberately focused scope, and new capabilities are added continuously: more actions on objects, user management, backup features and more. The [XO 6 and XO 5](xo6vsxo5.md) page presents the highlights of XO 6 and tracks what lives where today, and the best way to see what is new is simply to keep your Xen Orchestra up to date.

To explore the interface, start with [How XO is organized](../core-concepts/coreconcepts/coreconcepts.md).

## Follow each release

To know what each new version of Xen Orchestra brings:

- the [Xen Orchestra blog](https://xen-orchestra.com/blog/) presents every release and its main features,
- the [changelog](https://github.com/vatesfr/xen-orchestra/blob/master/CHANGELOG.md) lists every change, release by release.
