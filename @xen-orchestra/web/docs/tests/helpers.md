# Shared helpers by need (XO 6)

This page lists every helper in `src/test/` (`@/test/…`), grouped by what a test needs. Check it before you write a query, a mount, a mock or a test case. To build XO objects, use the [test data factories](./factories.md). Generic helpers from `web-core/test/` (`@core-test/…`) appear here where XO 6 uses them, and are described in [Shared test helpers](../../../web-core/docs/tests.md#shared-test-helpers).

When you add a helper to `src/test/`, list it here under its need, in the same change.

## Form messages

`form-messages.ts` builds the error message a field binding of a validated form carries. A form test can then check the exact error instead of using `toBeDefined()`:

```typescript
expect(form.passwordInputBindings.error).toEqual(dangerMessage(form.t('password-required')))
expect(form.usernameInputBindings.error).toEqual(invalidCredentialsMessage())
expect(form.hostInputBindings.error).toEqual(requiredMessage())
```

`requiredMessage()` is the message of a `required` rule that has no `withMessage` of its own. It is the app-wide `form:error:required` message, which `createGlobalTestConfig()` installs the same way `main.ts` does.
