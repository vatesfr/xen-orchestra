### `replace(value, replacement)`

> Recursively replace sensitive entries with a replacement value.

```js
import { replace } from '@vates/obfuscate'

replace({ username: 'foo', password: 'bar' }, 'obfuscated')
// → { username: 'foo', password: 'obfuscated'}
```

### `obfuscate(value)`

> Recursively replace sensitive entries with a special tag.

```js
import { obfuscate } from '@vates/obfuscate'

obfuscate({ username: 'foo', password: 'bar' })
// → {
//   username: 'foo',
//   password: 'obfuscated-q3oi6d9X8uenGvdLnHk2',
// }
```

### `merge(newValue, oldValue)`

> Replace entries obfuscated by `obfuscate()` in the new value by entries from the old one.
>
> This is especially useful to give an obfuscated value to a client, let them modify it, and then merge modified and unmodified values.

```js
import { obfuscate, merge } from '@vates/obfuscate'

const original = { username: 'foo', password: 'bar', token: 'baz' }

// compute an obfuscated value to send to a client
const obfuscated = obfuscate(original)

// let the client update any entries
obfuscated.token = 'qux'

// merge the updated value with the original one
merge(obfuscated, original)
// → { username: 'foo', password: 'bar', token: 'qux' }
```

### `redact(value, [isSensitive], [options])`

> Recursively replace sensitive entries with the same special tag as `obfuscate()`, whatever their type.
>
> Unlike `obfuscate()`, it uses a broader list of sensitive keys (`isExportSensitiveParam`) because redacted values are never merged back: it is meant for data leaving XO, such as support dumps or audit records. Keys are kept so that the structure stays usable.

Options:

- `replacement`: the special tag of `obfuscate()` by default
- `urls`: whether to also apply `redactUrls()` to the other strings, `false` by default

```js
import { redact } from '@vates/obfuscate'

redact({ username: 'foo', password: 'bar', cluster_token: { value: 'baz' } })
// → {
//   username: 'foo',
//   password: 'obfuscated-q3oi6d9X8uenGvdLnHk2',
//   cluster_token: 'obfuscated-q3oi6d9X8uenGvdLnHk2',
// }

redact({ error: 'cannot mount nfs://user:pass@host/path' }, undefined, { replacement: '*', urls: true })
// → { error: 'cannot mount nfs://*@host/path' }
```

### `redactUrls(string, [replacement])`

> Replace the credentials and the sensitive query parameters (e.g. `encryptionKey`) of the URLs in a string, wherever they are (e.g. in an error message).

```js
import { redactUrls } from '@vates/obfuscate'

redactUrls('s3://KEY:secret@s3.lan/bucket?encryptionKey=foo', '*')
// → 's3://*@s3.lan/bucket?encryptionKey=*'
```
